# Namma-HomeStay

An Android hospitality application for rural homestays to promote services digitally. Allows hosts to create profiles, upload images, update menus, communicate with travelers, and promote local guides.

## Tech Stack
- Kotlin
- Firebase Firestore
- Image Picker

## Setup
1. Open in Android Studio.
2. Add Firebase project and download google-services.json to app/.
3. Sync Gradle.
4. Run on emulator/device.
